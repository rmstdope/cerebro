cb-hjf — what kind of agent is this? The role, on a Fleet row

The Fleet list names nine agents. Nothing next to a name says what kind of agent it is, so the shape of the fleet — how many are planning, how many are building — is something you have to remember rather than see.

There is a catch, and it is the whole of this decision. When the whole window is given to the fleet list it already shows a Role column. The everyday screen does not: the fleet list sits in a narrow column beside the work list, and at that width the Role column is dropped and never seen. Every panel below is drawn at that everyday width. There is room for about two spare characters.
