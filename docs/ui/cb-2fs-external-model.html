External models for Copilot agents

A navigator defines an external OpenAI model once, then chooses it by name for any Copilot agent. An ordinary Copilot model remains an ordinary model name.

Define and choose an external model

.cerebro/agents.conf
# external model: name, provider, URL, access-key reference, and model
external research openai https://api.openai.com/v1 ${OPENAI_API_KEY} gpt-5.4

Beast   tool=copilot  model=research
Xavier  tool=copilot  model=gpt-5.6
Everything is in one place. The external model can be reused, but its URL, access-key reference, and model are written once. The key is a reference, never its secret value. Xavier's ordinary Copilot model remains unchanged.

When Beast starts

Session
launch: agents.conf ("Beast") -> copilot, external model "research" (OpenAI gpt-5.4)

This session is Beast of the Cerebro fleet rooted at /your/project/.

The confirmation appears before the session begins and identifies the external model without revealing credentials.

External model unavailable

Session
launch: external model "research" is unavailable; Beast will use Copilot's default model.

This session is Beast of the Cerebro fleet rooted at /your/project/.

The agent still starts. The confirmation says what could not be used and that Copilot's default model is running instead.

Narrow window

Session
launch: agents.conf ("Beast")
  -> copilot, external model
  "research" (OpenAI gpt-5.4)

The source, external-model name, and underlying model wrap together so the selected model cannot be mistaken for Copilot's ordinary choice.
