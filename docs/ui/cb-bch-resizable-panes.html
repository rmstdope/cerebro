cb-bch — the surface the navigator approved, 2026-09-08

Two rounds. This file is the specification for resizable panes in cerebro-tui. Where this file and either child bead's plan disagree, this file is right. It applies to the terminal view alone: M-x cerebro is read-only in this repository and is deliberately not given the terminal view's newer surfaces.

The work is split. cb-bch.1 is the size state and the keyboard chords; cb-bch.2 is mouse capture and everything the mouse does. Everything on this page under The chords is cb-bch.1; everything under The mouse is cb-bch.2.

1. What is fixed today

At a hundred columns and wider the left column is a hard 40 cells, Fleet takes its natural height capped at half that column, and Work gets the rest. None of it can be moved.

2. The chords — cb-bch.1

Ctrl-← and Ctrl-→ move the vertical divider one cell; Ctrl-↑ and Ctrl-↓ move a horizontal divider one row; Ctrl-= puts every divider back. They act from any focus and are held back from a focused live session, exactly as Tab, Shift-Tab and F1–F3 already are.

3. The mouse — cb-bch.2

Mouse capture is on for the whole run. That takes the terminal's own click-drag text selection and its scroll wheel away over the whole window, including over a live agent session; most terminals give them back while a modifier is held (Option on macOS Terminal and iTerm2, Shift elsewhere), and that is the terminal's behaviour rather than something this program can promise. The navigator accepted that cost knowingly. Mouse events are never forwarded into a session's pty, so an agent in the Session pane sees no mouse at all.

Dragging

Press on a divider and move: it follows the pointer live and both panes reflow every frame — the Session pane is a real pty, so the agent inside it is told its new size as the drag happens. A drag past a floor stops at the floor. Double-clicking one divider resets that divider alone.

A click selects and focuses

Clicking a Fleet row selects that agent and focuses Fleet; clicking a selectable Work row moves the cursor there and focuses Work; clicking the Session pane focuses it, which hands the keyboard to a live agent. Tab is the way back, as it already is. A click on a heading, a blank or any other unselectable line focuses that pane and changes nothing else.

4. What is not remembered

A size lasts until cerebro-tui exits and no longer. Nothing is written to disk: scroll offsets, focus, selection and the armed set are all memory-only in this crate by design, and the navigator chose to keep divider sizes in that company rather than introduce the crate's first on-disk preference. Sizes are kept per layout within one run, so narrowing the terminal below a hundred columns and widening it again restores what was set on the wide screen.

6. The hint line

^←→ size joins the hint line at the optional rank — the same rank as h health — so it is offered unconditionally and is dropped first and alone when the screen narrows, never costing a whole tier of the hints the navigator asked by name to keep. It arrives with cb-bch.1 and is unchanged by cb-bch.2.
