Stacked, independently scrolling widgets

Fleet uses its natural height up to half the available pane area. Work receives the remainder. Tab and Shift-Tab move focus; arrows and page keys scroll only the focused widget. The focused widget has a bright blue one-cell border drawn with thick line glyphs and a bold blue title. A refresh preserves both scroll positions independently, clamping only when new content is shorter.
