cb-3v5 — the surface the navigator approved, 2026-09-03

Two rounds. This file is the specification for how a navigator leaves a focused live session in cerebro-tui, and for every sentence the screen says while doing it. Where this file and the bead’s plan disagree, this file is right. It changes nothing any earlier file in the cb-kcs family decided: not a fleet row, not a lifecycle key, not a pane’s borders, not the Work pane’s own keys. It is the outbound half of the journey cb-d31 made inbound.

1. The rule

Tab becomes a second held-back key. A focused live session receives every key except Tab and Shift-Tab; both run the plain focus cycle, which from Session means Tab → Fleet and Shift-Tab → Work. Nothing else about the cycle moves, and no pane holding anything other than a live session changes at all.

Session pane holdsTabShift-Tab
a live session, focused→ Fleet (new; today the agent gets a tab byte)→ Work (unchanged)
Starting Name…→ Fleet (unchanged)→ Work (unchanged)
an ended pass (retained transcript)→ Fleet (unchanged)→ Work (unchanged)
a refused launch (red pane)→ Fleet (unchanged)→ Work (unchanged)
nothing at all→ Fleet (unchanged)→ Work (unchanged)

What it costs: no hosted agent ever receives a plain Tab again. What pays for it: Ctrl-I is a tab (0x09), and the forwarding table already maps every Ctrl-letter to its control byte — so an agent that needs a real tab still gets one, in two keys instead of one, with no code written for it. That fact is written down in the navigator’s operating guide (§4) and nowhere else.

Rejected, round one: “leave Tab to the agent and make Shift-Tab land on Fleet instead”. It costs the child nothing and still gets back to Fleet in one key — turned down because Shift-Tab would then mean one thing on a live session and another everywhere else, so the cycle stops being a cycle. Also rejected: “Tab held back and Shift-Tab also lands on Fleet” — leaving a session would have one destination, at the price of Work no longer being one key away from a session at all.

The header sentence replaces the whole header and is clipped, not wrapped. At 80 cells with the longest name on this roster it fits with room left: Psylocke has the keyboard | Tab leaves to Fleet, Shift-Tab to Work is 66 cells. Rejected wordings: Tab → Fleet, Shift-Tab → Work (nine cells shorter, but scans as a table where every other sentence on this screen is prose), and appending | Ctrl-I sends a Tab (clipped mid-word at 80 cells — the operating guide carries it instead).

4. Where Ctrl-I is written down

In docs/agent-workflow.md, the navigator’s operating guide, in the sentence that already describes Tab and Shift-Tab — and nowhere else. Not in the header, which cannot afford the cells; not in CLAUDE.md, which describes the rule rather than the hatch.

5. Unfocused, and the panes that never held the keyboard

None of these changes. A pane holding an ended pass, a refused launch, Starting… or nothing at all does not hold the keyboard, so both keys already ran the plain cycle and still do.
