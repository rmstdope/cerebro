cb-lz5.1 — Board A: the new stage gets a section of its own

A bead whose experience is agreed but whose build is not designed is a real waiting state — it is what the implementation-design agent picks up. In A it has its own Work-pane section, Experience agreed, sitting between Being planned and Unplanned, so the queue reads in the order work actually moves through it. It behaves like every other bead section: the cursor walks it, the priority keys work on it, Enter pins the bead.

1. The fleet running the two-agent variant

The roster carries experience and implementation-design instead of planner. Two beads have an agreed experience and none is being designed yet, so Ada is idle and Turing has just been started.

4. A bead sent back reads as a first-class thing to look at

Sent back means the experience agent must look again, so the bead leaves Experience agreed and returns to Unplanned, where the experience agent takes it. The section count moves, which is the signal.
