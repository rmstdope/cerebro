The idea

scripts/fleet-cost prints an aligned plain-text table by default, and the same answer as JSON under --json. The table is the whole point: what did this week cost is one command, with no jq to remember.

What it costs you

The question the bead was filed for is answerable in one command by somebody who has not read the script. And a percentage column makes the zero-bead third impossible to overlook, which a JSON array does not.

Against that: it is a second house style. work-beads and fleet-history both print JSON and nothing else, and this is the first script here that formats for a human. It is also more code — column widths, a total line, and a test for each.
