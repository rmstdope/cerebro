The lifecycle keys, as chosen

This is what cb-kcs.2.3 builds — s, f and k in the Ratatui view — agreed with the navigator over three rounds on 2026-09-01. It refines docs/ui/cb-kcs.2-split-console.html, which settled the screen these keys act on and already fixed the kill prompt, the two acted-upon lines and the refused-launch pane; everything here either repeats one of those verbatim or settles something that mockup left open.

  • Only k asks before acting. s and f act and say what they did.
  • f is a toggle: pressed again it clears the stop flag it set.
  • While handing over, f and k still act — that is how a handoff ever finishes — and s does not.
  • A key that cannot act says why, in gold, in the header's notice slot, in the sentences the Emacs view already uses.
  • This view acts on its own sessions only. An agent it did not start is refused.
  • Quitting with agents live is refused by a full-screen pane; any key returns.

The three keys, acting

Each line replaces the hints in the header, in the notice slot, and is cleared by the next keystroke.

Cerebro — supervising | Started Rogue.
Cerebro — supervising | Started Cyclops, and cleared a stale stop flag.
Cerebro — supervising | Cyclops will finish after this pass.
Cerebro — supervising | Cyclops will keep going.

The second line is a start that also removed a stop flag somebody had left set — an implementer started with one would stop again at once, so the flag goes with the start, and the line says so rather than deleting a file silently. The fourth is a second f: the flag it set is cleared and the agent goes on.

k asks, and the prompt names what a kill costs

Cerebro — supervising | Kill Cyclops? Its bead cb-42k stays claimed. y / n
Cerebro — supervising | Kill Cerebro? y / n

y kills. Every other key cancels, silently — the header goes straight back to its hints and nothing is said, exactly as a notice is cleared by the next keystroke. The cancelling keystroke is consumed: q at this prompt cancels the kill and does not also quit.

Handing over — f and k still act

project.conf now names Emacs while this view still hosts live agents. It keeps the lease so nobody starts duplicates, and it starts nothing itself; the two keys that end a session go on working, because ending them is how the handoff completes. The gold count is the only number that matters here, and it sits in the notice slot — a notice takes its place for one keystroke.

The header, at both widths

s/f/k start·finish·kill joins the hints while supervising, and it is what survives when the header runs out of room: the keys that change the fleet outlast the keys that move around it.

Quit, while agents are live

A hosted child dies with its parent, so quitting over a live agent would strand a claim, a worktree and an open pull request. The refusal takes the whole screen, because it is the one thing on it that stops you leaving. Any key returns, and that key does nothing else — the two keys the pane recommends are pressed after it has gone.

Cerebro — supervising | quit refused
3 live agents prevent exit
Cerebro is supervising Xavier, Beast and Cyclops.

Finish or kill every live agent before quitting.
  f  finish the selected agent after its pass
  k  kill the selected agent now

No agent was stopped. Any key returns.

The names wrap rather than truncating; the pane is the screen's height.
