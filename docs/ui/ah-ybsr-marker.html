ah-ybsr — the unverified marker, four shapes

You chose B — trust the file, mark it. This is the same six rows in each shape, mixing the three cases that must stay distinguishable: a proven row (Cerebro, once the carrier is fixed), two unproven rows whose files are being trusted (Wolverine mid-build, Moira waiting), a row already carrying the two existing suffixes (Storm, flagged and duplicated), a recycled pid whose args do not name it at all (Cyclops — proved not that session, so no mark: it stays dead), and a role with no file (Cypher). The marker must not be mistaken for the bold orange ? that means asking, which lives in the Agent column — Psylocke shows one for contrast.
