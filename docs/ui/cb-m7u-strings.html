5. The checker's output — every state

$ scripts/four-eye-sync          # whole
$ echo $?
0

$ scripts/four-eye-sync          # a carrier's block has drifted
drifted: templates/consumer-CLAUDE.md (block differs from templates/four-eye-principle.md)
$ echo $?
1

$ scripts/four-eye-sync          # a carrier lost a marker
unmarked: CLAUDE.md (no four-eye:begin/end pair)
$ echo $?
1

$ scripts/four-eye-sync          # the source itself is gone
missing: templates/four-eye-principle.md (the canonical block)
$ echo $?
1

$ scripts/four-eye-sync --help   # any argument at all
usage: four-eye-sync
$ echo $?
2

Same shape as scripts/tracked-links: no arguments, one line per finding on stdout, exit 1 when there is one, exit 2 for usage. Its suite tests/four-eye-sync.sh ends by asserting this repository's own copies agree, the way tests/tracked-links.sh does.

6. Deliberately unhandled

An empty canonical file is not a finding: a carrier whose marked region is also empty matches it, and the gate would be asserting that the policy is non-empty — which is a grep for prose content, and this repository does not do that. A consumer's own CLAUDE.md is never read by this script; only the two files in this repository are.
