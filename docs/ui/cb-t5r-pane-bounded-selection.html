Copying stays inside one pane

Hold Shift and drag across displayed text to copy it. The copy follows the pane where the drag began: it preserves the visible wrapping and never takes text from another pane.

A long range

Holding the pointer beyond the top or bottom edge scrolls only the pane where copying began. The copied range grows through that pane's newly displayed rows; the other panes do not move or join the copy.

When content changes

If new content arrives while a copy is underway, the selected range remains the originally displayed text. New or replaced rows do not change the range or join the copied text.

Quiet and non-invasive

The visible selection is the only copy feedback: there is no new message while copying or afterward. Releasing the mouse leaves that selection visible; another Shift-drag replaces it. A Shift-drag neither selects a row nor changes keyboard focus, so keys continue to control the same pane or session as before.

Empty, loading, error, and narrow panes

A drag copies only text that is visibly present. In an empty pane it selects nothing. In a loading or error pane, its visible text can be copied like any other displayed text. The boundary follows the pane's border at every width, including the stacked narrow layout, and preserves every displayed wrapped line as shown.
