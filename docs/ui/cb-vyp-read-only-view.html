Agreed read-only Ratatui view

The standalone cerebro-tui is a live, read-only companion to the Emacs supervisor. It writes no state and exposes only scrolling, refresh, and quit keys. Up/Down scroll one line; PageUp/PageDown scroll one viewport. A refresh preserves the current line and clamps it only when the new content is shorter; while one is running the header says refreshing... and another g is ignored. Emacs-only armed/standby state is not a shared contract, so an agent with no live session reads as dead here even when Emacs intends to start it later.
