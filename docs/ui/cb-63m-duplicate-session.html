cb-63m — Option A: a second session shows on the agent's own row

The State column gains a ×N suffix, in the warning face, when this consumer's fleet has more than one session carrying that name — the same slot the stop-flag ■ uses. Nothing else moves. Pressing s, k or f on such a row names the pids in the echo area; ending the extra one is done from its own terminal.
