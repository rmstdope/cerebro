cb-azi — what each agent cost on each bead

The agreed design, chosen by the navigator over two rounds. Every number below was measured on this checkout with scripts/fleet-cost, not invented.

The decision, in one line

One row per bead-and-agent, replacing --by-bead — not a cross-tab with agents as columns, and not a fourth mode alongside the existing three.

The four choices, and what was rejected

DecisionChosenRejected, and why
OrientationOne row per bead-and-agent Agents as columns — the cross-tab originally asked for. It grows ~9 columns per agent, and this roster is 8 names, so it stops fitting a terminal on this fleet's own data.
RepetitionTITLE on every row Title on the first row of each bead only — a blank meaning "same as above" is something none of the existing tables ask a reader to hold, and it breaks a grep for an agent. Bead-as-heading — stops being a table and pipes badly.
SHAREShare of that bead: each bead's rows sum to 100% Share of the fleet's whole spend (what it means today), and dropping the column altogether.
PhaseDropped by default, behind --phase Always splitting by phase — it makes every agent who worked twice on a bead into two rows.

Why the long form, in one picture

The same week, as the rejected cross-tab, once the roster is what it actually is:

BEAD     TITLE               Cyclops  Xavier   Beast  Cerebro  Psylocke  Cypher   Moira   Forge      TOTAL
cb-ue0   Launch startup a…    1719.5    0.0!       -        -         -       -       -       -     1719.5

107 columns before the title has any room. The long form is a fixed ~60 columns whatever the roster does, and pipes into grep, sort and awk.

The unpriced trap, which this shape answers for free

Measured on cb-ue0: Cyclops build 1719.5, Xavier plan 0.0 — ten requests, none of them priced, so the planning reads as though it cost nothing.

UNPRICED is a real column here rather than a mark to invent, so the 0.0 / 10 pair sits on one row and cannot be misread as free. In the rejected cross-tab the same fact needed a suffix, a bracketed count or a footnote — all three were mocked, and all three were annotations on a number rather than a column of the table.
