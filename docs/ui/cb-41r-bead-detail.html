cb-41r — the surface the navigator approved, 2026-09-03

Three rounds. This file is the specification for what Enter does on a bead row in the Work pane of cerebro-tui, for everything the Session pane draws while a bead is in it, and for every sentence the screen says. Where this file and the bead’s plan disagree, this file is right. It changes nothing any earlier file in the cb-kcs family decided: not a fleet row, not a lifecycle key, not a pane’s borders, not the priority keys, not Enter on a +N more row. It is the third of the three navigation beads, beside cb-d31 (Enter into a session) and cb-3v5 (Tab out of one), and it agrees with both.

1. The rule

Under Work focus, Enter on a bead row pins that bead’s detail in the Session pane and moves focus there. It stays pinned until it is dismissed: it survives moving the Work cursor, moving the fleet selection, a session starting or ending on its own, and the thirty-second board refresh. The selected agent’s session goes on running underneath — it is not killed, not paused, not scrolled; it is simply not what this pane is drawing.

Cursor is onEnter under Work focus
a bead row, no bead pinnedpins that bead, focus moves to the Session pane
a bead row, a different bead pinnedreplaces it with this one, focus moves to the Session pane
a bead row, this bead already pinnedunpins it — the session comes back and focus stays on Work
a +N more rowopens/closes that section (cb-kcs.5.4) — unchanged, focus does not move
a sweep findingnothing, and it says nothing. x is the finding’s key and it already asks its own question

Rejected, round one: a pane that follows the Work cursor, showing whichever bead the cursor rests on with Enter only moving focus. Nothing to dismiss and no mode — turned down because the Work list and a running session could then never be on the screen together, and because it spawns a read per rested cursor position rather than per key press. Also rejected: opening the bead in place in the Work pane, like a +N more section. It keeps one meaning for Enter in that pane and leaves the agent on screen beside what you are reading — turned down on width: the left column is a fixed 40 cells, so a design field would be read at 36 columns while the Session pane beside it has everything else on the screen.

No new key is spent, and no key changes meaning: Enter already means “act on the thing under the cursor” in both panes. q and Esc still quit the program and are not repurposed as a dismissal — a navigator who has learned that Esc quits must not have it mean two things. Rejected: s, k and f all dropping the bead (one rule for the three lifecycle keys, at the price of k throwing away what you were reading); and nothing but the two Enters dropping it, which is simpler still and lets s start an agent while the pane refuses to show it.

5. The header

Work focused, cursor on a bead row
Cerebro[tui supervises] | Tab/Shift-Tab pane | ↑/↓/PgUp/PgDn move | s/f/k agent | 0-4/+/-/u priority | Enter bead | g refresh | q/Esc/Ctrl-C quit

One new clause, Enter bead, joining the priority clause on a bead row and following the rule every existing clause follows: a clause is shown only while its key would act. It is Enter session’s shape exactly — key, then what it acts on. Rejected: Enter read (says what you get; the only clause shaped that way) and Enter show bead (matches Enter show all, at three words). A +N more row keeps Enter show all, and Fleet focus keeps Enter session; nothing else in the header changes.

7. Two rules carried over rather than decided

The keyboard. A pinned bead is not a live session, so no key is forwarded anywhere: ↑/↓/PgUp/PgDn scroll it, Tab/Shift-Tab leave, q/Esc quit. Exactly the retained-transcript rules, and the header keeps its own line rather than being replaced by … has the keyboard. The hint after the title follows the live pane’s own spelling: [Shift-Tab leaves] focused, [Tab to focus] unfocused.
The lease. This is the navigator’s own act and it reads the shared board, so it works on a read-only view exactly as it does on a supervising one — like x, like the priority keys, like cb-d31’s Enter. There the way back is Tab or a second Enter on the bead row, since that pane holds no session to return to.
