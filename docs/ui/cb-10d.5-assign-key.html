cb-10d.5 — the give key, agreed 2026-09-14

Four rounds. The navigator's own hand: a on a piece of work in the Work pane opens a short list of agents, and Enter gives it to one. The bead's acceptance field carries the same decisions in words; where this file and a plan disagree, this file is right. It reuses docs/ui/cb-10d.1-starting-row.html for the row and docs/ui/cb-21g-board-writes.html for the dim-then-finished line, and changes neither.

Work focus only. Opens directly beneath the row it was pressed on. Every agent whose role takes work is listed, in roster order, all of them; agents who cannot take this one right now are dim with the reason and the cursor skips them. Roles that never take work (Cerebro, Moira, Psylocke, Cypher, Forge) are never listed. The list updates in place as the fleet changes. Esc or any other key — a click included — closes it silently and is used up (q closes the list, it does not quit). On close the cursor is back on the piece of work.

2. Giving it

Cerebro — supervising | Giving cb-44b to Rogue…
Cerebro — supervising | Gave cb-44b to Rogue

her row, the moment she has it — the same row the view's own hand-out shows

│◌ Rogue        starting    cb-44b     │
The key only records who the work is for; it starts nothing itself. The supervising window starts her through her usual trigger, and the row follows cb-10d.1: starting, up, then working. The key works the same from a read-only window.
