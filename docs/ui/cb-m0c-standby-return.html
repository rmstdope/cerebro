cb-m0c — a design agent that comes back

Every piece of work now passes two stages before anyone builds it: someone agrees what a person will see, then someone works out how it gets built. Each stage has its own agent, and each agent has a row on the fleet screen. The row is a promise: while it is blue the screen will start that agent again by itself, the moment there is work for it. While it is grey nothing ever will, until you start it by hand.

Agreed with the navigator, 2026-09-09. Section 3 was chosen in round one; section 5 was settled in round two.

2. What it should do

A finished pass is not a retirement. The row goes back to ready and waiting, carrying the short note that says what would wake it — and the next piece of work needing a design starts it again with nobody pressing anything.
