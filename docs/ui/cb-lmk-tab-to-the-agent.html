cb-lmk — the surface the navigator approved, 2026-09-12

Two rounds. This file is the specification for giving Tab and Shift-Tab back to a hosted agent in cerebro-tui. Where this file and the bead's plan disagree, this file is right.

1. The arrangement

KeyA live session has the keyboardNo session has the keyboard
Tabreaches the agentwalks the panes forward: Fleet → Work → Session
Shift-Tabreaches the agentdoes nothing at all
F1 / F2 / F3the only way out — Fleet, Work, Sessionjump to Fleet, Work, Session

Every other key is unchanged: g, h, x, q, the arrows, the priority digits and the Shift-arrow sizing chords all behave exactly as they do today, and all of them are still held back from a focused live session.

The ordinary hint line, when nothing has the keyboard

 g refresh   h health   Tab/F1-F3 pane   ↑/↓/PgUp/PgDn move   x act   q/Esc/Ctrl-C quit
— the same window, narrowed: the clause survives as one piece, or not at all —
 g refresh   Tab/F1-F3 pane   q/Esc/Ctrl-C quit

One clause, not two: the F-keys stay visible for exactly as long as Tab does and disappear with it, so a narrow window never advertises the pane walk while hiding the only way out of a focused session.

The frame said [Tab leaves], and Enter on the row opens the bead again, so nothing shouts at the navigator for using the key they were told to use. This is a change in behaviour as well as wording: the advertised way out used to be Shift-Tab, which left the bead open. The same rule covers the health report and a pinned bead alike, which is what keeps one pin pattern rather than two.

Shift-Tab outside a session

 — Shift-Tab pressed: the screen does not move, and nothing is said. —

The view has a standing habit that a silently dead key is what its whole key vocabulary exists to prevent. This is the deliberate exception, and the reason is the point of the change: the key is not the view's any more. Anyone with the old backwards-walking habit presses it once, sees nothing, reads Tab/F1-F3 pane on the hint line, and has the replacement.

4. Considered and rejected

Instead ofRejected because
<Name> has the keyboard | F1/F2/F3 to leaveshorter, but leaves the navigator guessing which of the three gets them back to the list of agents
<Name> has every key except F1 Fleet, F2 Work, F3 Sessionstates the whole rule in one breath, and is the longest of the three
Tab pane and F1-F3 jump as two clausesbuys room on a wide window and gives the jumps up first on a narrow one — so a small terminal would advertise the pane walk while hiding the only way out of a focused session
[F1-F3 leave] on a focused session framefour cells narrower; the spelled-out form was preferred where there is room for it
[F2 leaves] on a pinned beadpreserves exactly what Shift-Tab did — the bead stays open behind you — but advertises a key that lands in a pane the navigator may not have wanted
[F1-F3 leave] on a pinned beadone rule for everything the box can hold, but the line cannot say that F1 closes the bead while F2 and F3 leave it open
A gold notice when Tab closes a pinned beadwould say what happened and how to undo it, at the cost of one line of noise every single time the navigator steps out of a bead — and the frame already said [Tab leaves]
A gold notice on a dead Shift-Tab, always or once per runhonours the dead-key rule and teaches the replacement in the moment the habit fires; rejected because the key is deliberately the agent's now, and a once-per-run notice would be the only thing in this view that behaves differently the second time it is done
