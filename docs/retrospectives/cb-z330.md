## The prepared branch name could not be pushed

**What happened.** `git push -u origin cb-z330` from the prepared worktree failed with
`! [remote rejected] cb-z330 -> cb-z330 (failed)` and no further reason; `gh pr create` then
failed with "Head sha can't be blank". Pushing the same commit as
`cb-z330:cb-z330-epic-candidates-skip-events` succeeded at once.
**Why.** Not established. `scripts/prepare-worktree` names the branch `<id>`; `beads-workflow`'s
conventions name it `<id>-short-description`. The remote refused the bare id and gave no reason.
**Cost.** One failed push and one failed PR create; a few minutes.
**Prevent by.** `scripts/prepare-worktree` creating the branch under the name the conventions
give, or `skills/produce-bead` *Building* saying to push as `<branch>:<id>-short-description`.
**Seen before.** No.
