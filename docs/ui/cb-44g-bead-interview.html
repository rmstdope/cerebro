cb-44g — three shapes for “Cerebro interviews before it files a bead”

The same request, put to Cerebro three ways. In every variant the bead ends unranked at P4 and the existing ranking pass runs on it afterwards; what differs is how many times the navigator is interrupted, and whether they see the bead before it exists.

Decided, 2026-09-08. Option B — a conversation, then a draft the navigator approves before anything is written. Rounds are not capped: it keeps asking until it can describe the work. Before it interviews it searches the board and shows anything close. “Just file it” is honoured, and the report names what went unanswered. A request holding several beads is named as such and asked about, never split silently. After filing it offers the ranking once, and drops it if the navigator does not take it. The skill is invocable by hand as a slash command as well as loaded by Cerebro.

The request throughout, typed into a running Cerebro session:

> the fleet view should show me which bead each implementer is on in the session pane header
