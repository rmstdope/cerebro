1. Not all spend is priced. 53 of 2368 usage events (2.2%) carry a null cost — every gpt-5.3-codex request (33), a local Qwen3.8-27B (7), and gpt-5-mini (13). They are real requests that the store records no AIC for.

The log holds gate, review, ci and merge — but on every bead measured, the priced events land in build and plan only. cb-ue0's whole intervals are working/build ×2 and asking/build. So the phase view is honest and free, but today it mostly prints one row per agent. It gets better as agents write phases more finely; it is not a headline feature.
