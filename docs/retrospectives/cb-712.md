# cb-712 — the silent bucket lookup came back in the fixtures

This bead existed to remove one failure mode: a bucket asked for by a key nobody
placed answers `nil`, which no reader can tell from an empty bucket. The
production side got `cerebro--bucket`, which signals on a key that is not one of
`cerebro--bead-buckets`, and the plan said in as many words that nothing outside
that accessor may call `plist-get` on a bucket plist, *including in tests*.

The test helper this bead added, `cerebro-test--buckets`, called `plist-get` on a
bucket plist. A fixture written `(cerebro-test--buckets :megred beads)` was
accepted, dropped those beads, and handed back a well-formed, complete, entirely
empty plist; every assertion after it would have passed against nothing. The
accessor cannot catch that, because the typo never reaches a reader.

Two things are worth keeping:

**The rule was written for readers and the fixture was not thought of as one.**
`plist-get` was removed from every call site in `cerebro.el` and left in the one
place in `cerebro-test.el` that constructs the same shape. A discipline stated as
"no reader may" does not cover the thing that builds the value, and the builder
is where the previous instance of this defect (cb-wfb) actually hid.

**What found it was a review of the diff, a second time.** The gate was green
with the helper as first written, exactly as it was green through cb-wfb. That is
the same class of defect on its second occurrence, so it now has a check that
fires on it: `cerebro-test/the-bucket-fixture-refuses-a-key-it-cannot-place`
holds the fixture to the same refusal the accessor makes.

One process note: Copilot's review was requested when PR #209 opened
(`request-review` exit 0) and never arrived in ~24 minutes, so the standing
approval did not cover a merge and the bead was handed to the navigator. The
review that found the above was one the navigator asked for by other means. A
requested review that never arrives is not the same as one that cannot be
requested, and the difference cost this bead a session boundary.
