Full strength or faded?

Faded — the role sits behind the name and the state:

● Cyclops   imple… build    cb-21g
◌ Beast     build… standby  → ux agre…

Full strength — the role reads as equal to what the agent is doing:

● Cyclops   imple… build    cb-21g
◌ Beast     build… standby  → ux agre…
Faded is quieter to scan past and easier to pick out as a column; full strength is easier to read on the row you are looking at.

Wider only when the window can spare it

The list starts wide when there is room left over for the agent’s screen, and narrow when there is not. Costs one rule that is invisible until you meet it on a different machine.

Either way both widths can still be dragged or keyed at any time, and Shift-Home puts them back.
