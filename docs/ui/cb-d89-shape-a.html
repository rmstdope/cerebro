cb-d89 — Option A: JSON only, the work-beads shape

Every number below is real. It was produced by running the join against this machine's ~/.copilot/session-store.db and this checkout's .cerebro/state/transitions.jsonl while planning this bead. Nothing is invented.

The idea

scripts/fleet-cost prints a JSON array on stdout and nothing else, exactly as scripts/work-beads and scripts/fleet-history do. Every human-readable question is a jq one-liner, documented in the script's header the way fleet-history documents its own.

The null bead is the zero-bead bucket — see the question about it below. It is one row in the array like any other, so jq handles it without a special case, and add over .aic is the true total by construction.

What it costs you

Everything is one jq away, and the two neighbours already work this way — so there is one house style rather than two, and the script stays small enough to read in one sitting.

Against that: "what did this week cost" is never one word. It is always a jq incantation, and the navigator either remembers it or reads the header again every time.

The refusals

Loud, like both neighbours — non-zero, a line on stderr, nothing on stdout.
