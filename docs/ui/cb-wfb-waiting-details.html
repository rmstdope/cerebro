(b) updated_at, the only timestamp bd already keeps. Always a number — but it moves on any edit, so a comment or a priority change resets it:

cb-ddd has been parked six days; it reads 8m because you changed its priority a moment ago. The column is then "last touched", not "how long you have been sitting on this" — which is the question the section exists to answer.
